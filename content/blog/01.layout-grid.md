# Requirement

## 1. split main content from suplemenatry

- md 에는 Main 글 ( 제목, 본문, 주석 등등)과 Main 글을 설명하는 부분으로 구분된다.
- md 에 Main 와 Suplemantry 부분을 구분할 수 있는 식별자 코드가 있다.
- mobile 에는 Main 글 아래에 설명부분이 순차적인 흐름을로 게제된다.
- ui 가 충분히 커지면 2 column 으로 나란히 배치하게 된다.
- 설명 부분이 Main 보다 길어지는 경우는 Collapisble, Accordion, Ellipsis 등으로 사이즈를 조절한다.

## 2. 구현 방향

MD 파일은 공식 본문만 보관(Git), 보충 설명은 DuckDB에 저장하고 우측 패널에 동적으로 표시한다.

- 보충 설명은 우측 패널 상단에서 heading 기준으로 섹션별 그룹핑 표시
- MDC 문법 지원: `::XlsxTable`, `::Gof` 등 프로젝트 컴포넌트 포함 가능
- status 워크플로: draft → pending → approved

## 3. Sidebar 코멘트 통합

보충 설명을 `doc_comments.type = 'supplement'` 로 저장하여 기존 코멘트 시스템과 통합.
승인된 supplement 는 우측 패널 "보충 설명" 섹션에 표시된다.
